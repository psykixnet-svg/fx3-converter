# 通貨コンバーター (FX)

海外出張向けに「円 ⇄ 現地通貨 ⇄ 同行者の通貨」を一度の入力で同時表示するブラウザツール。

- 画面上の通貨は **2〜5 行で可変**（JPY 固定 + 外貨1〜4）。行数に応じて数値サイズと余白が自動縮小
- 末尾の「＋ 通貨を追加」で追加、各外貨行の「× 外す」で削除（5秒間は取り消し可能）
- どの行に入力しても他の行が連動
- 「UPDATE」で取得したレートを端末（localStorage）に保存し、以後はオフラインで計算可能
- JPY 行にはクロスレートではなく **レートの取込時刻と鮮度**（今日 / N日前、3日以上は警告色）を表示
- レート取得元: open.er-api.com → fawazahmed0 currency-api（jsDelivr / pages.dev）の順に試行
- 26通貨対応、外部CDN不使用のシングルファイル

## デザイン

案 3a "Ledger × Lime"。紙の台帳レイアウト（罫線と右寄せの等幅数字）に、基準行だけライムの塗り。
配色 paper `#EDEEE9` / ink `#1F2233` / line `#D3D5CE` / mute `#565B69` / lime `#C6F24E`。
書体は端末フォールバックのみ（見出し=明朝系、UI=システム sans、数値=等幅）。

## ファイル

| ファイル | 内容 |
|---|---|
| `index.html` | 本体（単体で動作） |
| `sw.js` | Service Worker。HTTPSで一緒に配信するとオフライン起動に対応（キャッシュ名 `fx3-v2`） |

## 使い方

`index.html` をブラウザで開くだけ。スマホのホーム画面に追加するとアプリのように使えます。
旧バージョンの保存データ（`c1`/`c2` 形式）は起動時に自動で移行されます。
